# Create an Event

> **Audience:** Event Manager
> **Required role:** Organisation Admin
> **Feature status:** Available
> **Last verified:** Admitto 0.4.12

Create the event before importing attendees or preparing messages.

## Create a new event

1. Open **Events**.
2. Select **Create event**.
3. Enter a clear event title.
4. Set the event date, time, and time zone carefully.
5. Add the location and capacity when your event uses them.
6. Save the event, then open it from the events list.

The event is now ready for setup. Continue with [Event Overview and Settings](Event-Overview-and-Settings).

## Before you add attendees

Check the title, date, time zone, location, and capacity. These details appear throughout event work, so correcting them early avoids confusion later.

If your organisation uses branding, add it in **Event settings** before sending messages. Use only images your organisation is allowed to publish.

## Active and archived events

The event list separates active and archived events. An archived event is read-only. A Superadmin can restore it if further work is needed.
