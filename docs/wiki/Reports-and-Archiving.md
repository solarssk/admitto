# Reports and Archiving

> **Audience:** Event Manager
> **Required role:** Organisation Admin
> **Feature status:** Available
> **Last verified:** Admitto 0.4.12

Use **Reports** to review attendance after check-in begins or after the event ends.

## Review attendance

The Reports page can show:

- Overall attendance.
- Admissions over time.
- Attendance by ticket type.
- Attendance confirmation status.
- Check-in method and device summaries.
- The admission log.

Use filters when you need to answer a specific event question. Check the event time zone before interpreting times in the admission log.

## Export data

Use the page's export control to download the available report. Keep exported data only as long as your approved event process requires. Store it in an approved location and do not send it to people who do not need it.

## Archive an event

Archive an event only after reporting and any approved follow-up are complete.

1. Open **Event settings**.
2. Open the archive controls.
3. Read the confirmation message.
4. Confirm the archive.

An archived event is read-only, including check-in. A Superadmin can restore it if work must continue.
