# Managing Attendees

> **Audience:** Event Manager
> **Required role:** Organisation Admin
> **Feature status:** Available
> **Last verified:** Admitto 0.4.12

Use **Attendees** to view the people invited to an event and their event status.

## Add one attendee

1. Open **Attendees**.
2. Select **Add attendee**.
3. Enter the required contact details and any event details your team needs.
4. Save the record.
5. Open the attendee record to check that the details are correct.

For many attendees, use [Importing Attendees](Importing-Attendees) instead.

## Review the list

Use search, filters, and the visible status columns to find attendees. Review ticket, delivery, and check-in information before taking an action.

Open an attendee to:

- Edit approved attendee details.
- Review ticket, email, and check-in status.
- Add or read event notes when your team uses them.
- Review issued items.
- Take permitted actions such as resending a ticket or changing pass status.

## Keep records accurate

Use the attendee's current status before sending a ticket or admitting them. Do not create duplicate records to correct a spelling mistake; update the existing attendee when the event policy permits it.

The attendee list also supports export for approved event work. Use [Reports and Archiving](Reports-and-Archiving) for attendance reporting.
