# Reference and Troubleshooting

> **Audience:** All staff
> **Required role:** Any staff role
> **Feature status:** Available
> **Last verified:** Admitto 0.4.12

## Status labels

| Label | Meaning |
|---|---|
| Available | Supported and ready to use in the current release. |
| Preview | Available, but may change before a later release. |
| Planned | Not available yet. |
| Deprecated | Still visible for now, but planned for removal. |

## Useful terms

| Term | Meaning |
|---|---|
| Organisation | The group that owns an event. |
| Event Manager | An Organisation Admin who prepares an event. |
| Operator | A person assigned to run check-in for an event. |
| Attendee | A person invited to the event. |
| Ticket type | A category used to group attendees. |
| Pass | An attendee's event entry status. |
| Check-in | Recording that an attendee has arrived. |
| Archived | Read-only; the event cannot be changed or used for check-in. |

## Common problems

### I cannot see an event or action

Check that you are signed in with your own account and have the right role. Ask a Superadmin to review access; do not use another person's account.

### My import has invalid or skipped rows

Read the validation summary, correct the source file, and import again. See [Importing Attendees](Importing-Attendees).

### A ticket did not arrive

Ask an Event Manager to review the attendee record and delivery log. See [Sending Tickets and Delivery](Sending-Tickets-and-Delivery).

### A ticket cannot be checked in

Check the on-screen result and follow the event lead's process. Use manual lookup only when it is enabled. See [Operator Quick Start](Operator-Quick-Start).

### I found a security or privacy concern

Do not add details to this Wiki. Follow the repository's [security reporting policy](https://github.com/solarssk/admitto/blob/main/SECURITY.md).
