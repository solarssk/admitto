# Operator Quick Start

> **Audience:** Check-in Operator
> **Required role:** Check-in Operator for the event
> **Feature status:** Available
> **Last verified:** Admitto 0.4.12

Use this guide when you are working at the event entrance. Your job is to check a ticket, confirm the attendee, and follow the event's agreed entry process.

![Check-in screen showing a fictional successful admission](assets/checkin.png)

## Before the first attendee

1. Sign in with your own account.
2. Open the assigned event.
3. Check that the event title and date are correct.
4. Prepare the scanner or camera according to the device instructions.
5. Scan one approved test ticket with the event lead.

## Scan a ticket

1. Open **Check-in**.
2. Scan the attendee's QR ticket.
3. Check the name shown on screen.
4. Follow the on-screen result.
5. Confirm admission when the event asks for confirmation.
6. Issue any item shown for the attendee, if required.

## If scanning does not work

Use manual attendee lookup only when the event has enabled it. Check the attendee's name carefully before confirming entry.

If the result says the ticket cannot be used, pause and follow the event lead's procedure. Do not admit the attendee by creating a new record or using another person's ticket.

## During and after your shift

Keep the device on the assigned event. Tell the event lead about repeated errors, unexpected results, or a device problem. Before you leave, make sure the next operator knows which event is open and that the device is ready.
