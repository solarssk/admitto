# Requirements and Fulfilment

| Field | Value |
|---|---|
| **Audience** | Event Managers |
| **Required role** | Organisation Admin |
| **Feature status** | Available |
| **Last verified** | Admitto 0.4.13 |

Use this area to decide what attendee information the event needs, what operators hand out, and how check-in behaves.

## Choose the right page

| Need | Page |
|---|---|
| Group attendees for import, filters, communication, check-in, and reports | [Ticket Types](Ticket-Types) |
| Store event-specific attendee information | [Custom Attendee Fields](Custom-Attendee-Fields) |
| Configure badges, materials, operator confirmation, lookup, and screen flow | [Event Items and Check-in Behaviour](Event-Items-and-Check-in-Behaviour) |

## Recommended order

1. Create ticket types before preparing attendee data.
2. Create custom attendee fields before adding their columns to an import file.
3. Configure event items and check-in behaviour before the operator test.
4. Test the complete flow with a synthetic attendee and ticket.

Changes in this area can affect imports, attendee forms, check-in, and reports. Avoid changing operator behaviour while active admission is in progress.
